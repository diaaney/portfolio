# Diane Charcoal Fixed Grain

`diane-charcoal-fixed-grain.kpp` is a Krita brush preset based on Diane's `h) Charcoal pencil large` copy. It keeps the embedded charcoal pattern and masking brush. Pressure no longer controls opacity, flow, or texture strength in either brush. Size still responds to pressure.

The preset was built from Diane's latest saved copy with `build_fixed_grain.py`. The fixed texture strength remains at 48%.

To install it in Krita, use the folder icon in the brush preset chooser (`F6`) and select the `.kpp` file, or copy it into Krita's `paintoppresets` resource directory and restart Krita.
